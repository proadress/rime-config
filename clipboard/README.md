# Clipboard configuration

Maccy is the clipboard manager on this Mac. It is installed with Homebrew and
its portable settings are recorded in `maccy/settings.sh`.

Current policy:

- history is limited to 500 items;
- `Command` + `Shift` + `C` opens history;
- selecting an item pastes it automatically;
- Maccy's built-in confidential and transient pasteboard-type exclusions remain
  enabled;
- the local history database is never exported.

Add password managers, authenticator apps, banking apps, or other sensitive
apps to Maccy's Ignore list when they are installed.

Never store clipboard contents, history databases, passwords, tokens, one-time
codes, private images, or copied files in this repository.
